## 构词法与词形变化

> **速查结论：**派生或合成可形成新词；books等数变化仍是同一名词的形式变化。

### 规则、例句与使用边界

**构词法（word formation）= 英语造新词的规律，主要有四种：派生、合成、转化、缩略。**

一句话记住：**会构词法 = 背一个词能推出好几个词，还能猜出生词意思。**

**中英对照案例**：
1. happy（开心）→ **un**happy（不开心）（派生：加前缀）
2. teach（教）→ teach**er**（老师）（派生：加后缀）
3. class + room → **classroom**（教室）（合成：两个词拼接）
4. water（水）→ to **water** flowers（浇花）（转化：名词变动词）

**核心规则**：四种构词法——派生法、合成法、转化法、缩略法。

## 派生前缀

> **速查结论：**un-、im-、re-等提供意义线索，但要遵守实际词形。

### 规则、例句与使用边界

**派生法（derivation）= 在词根前面加前缀或后面加后缀，构成新词。**

**核心规则**：
1. 前缀一般改变词义，不改变词性；
2. 后缀一般改变词性，不改变核心词义。

**核心分类**：

| 前缀 | 含义 | 例子 |
|---|---|---|
| un- | 不 | happy → unhappy、kind → unkind |
| dis- | 不/相反 | agree → disagree、like → dislike |
| im-/in-/ir- | 不 | possible → impossible、correct → incorrect |
| re- | 再/重新 | write → rewrite、build → rebuild |
| pre- | 预先 | view → preview、school → preschool |

**中英对照案例**：
1. happy（开心的）→ **un**happy（不开心的）
2. possible（可能的）→ **im**possible（不可能的）
3. write（写）→ **re**write（重写）

**易错误区**：前缀有固定搭配，不能随意混用：unhappy、impossible 是固定搭配，imhappy 是错的。

## 派生后缀

> **速查结论：**词尾帮助猜词性，不能代替句中位置与词义判断，如friendly是形容词。

### 规则、例句与使用边界

> **为什么按词性分类最有价值**：背单词时，只要记住"看到某个词尾多半是名词/形容词/副词"，再结合它前后的位置，就能很快猜出它是哪个词性。下面按"会造出哪种词性"来分组记，最实用。

#### ① 名词后缀（→ 名词 noun）

| 后缀 | 作用 | 例子 |
|---|---|---|
| -er / -or | 表"人/做某事的人" | teach→teacher 老师、act→actor 演员 |
| -tion / -sion | 表动作/状态的结果（常由动词变来） | educate→education 教育、decide→decision 决定 |
| -ness | 表性质/状态（常由形容词变来） | happy→happiness 幸福、kind→kindness 善良 |
| -ment | 表动作/结果（常由动词变来） | develop→development 发展、agree→agreement 同意 |
| -ity / -ty | 表性质/状态（常由形容词变来） | real→reality 现实、safe→safety 安全 |
| -ance / -ence | 表状态/性质（常由动词或形容词变来） | important→importance 重要、differ→difference 不同 |
| -th | 表性质/状态（常由形容词变来） | true→truth 真相、warm→warmth 温暖 |
| -ist | 表"做…的人/专家" | art→artist 艺术家、science→scientist 科学家 |
| -ship | 表身份/状态/关系 | friend→friendship 友谊、leader→leadership 领导力 |

**中英对照案例**：
1. happy（快乐的）→ happi**ness**（幸福，名词）
2. develop（发展）→ develop**ment**（发展，名词）
3. act（表演）→ act**or**（演员，名词）

#### ② 形容词后缀（→ 形容词 adjective）

| 后缀 | 作用 | 例子 |
|---|---|---|
| -ful | "充满…的" | care→careful 细心的、use→useful 有用的 |
| -less | "没有…的" | care→careless 粗心的、use→useless 没用的 |
| -y | "多…的" | sun→sunny 晴朗的、rain→rainy 多雨的 |
| -ous | "…的" | danger→dangerous 危险的、fame→famous 著名的 |
| -al | "…的/与…有关" | nation→national 国家的、nature→natural 自然的 |
| -ive | "…性的/有…倾向" | act→active 积极的、create→creative 有创造力的 |
| -able / -ible | "能…的/可…的" | read→readable 可读的、enjoy→enjoyable 令人愉快的 |
| -ic | "…的/与…相关" | base→basic 基本的、science→scientific 科学的 |

**中英对照案例**：
1. care（关心）→ care**ful**（细心的）/ care**less**（粗心的）
2. danger（危险）→ danger**ous**（危险的）
3. sun（太阳）→ sun**ny**（晴朗的）

#### ③ 动词后缀（→ 动词 verb）

| 后缀 | 作用 | 例子 |
|---|---|---|
| -ize / -ise | "使…化" | real→realize 实现、modern→modernize 使现代化 |
| -en | "使变得…" | wide→widen 加宽、short→shorten 缩短 |
| -ify | "使…化/使成为" | simple→simplify 简化、beauty→beautify 美化 |

**中英对照案例**：
1. wide（宽的）→ wid**en**（加宽，动词）
2. real（真实的）→ real**ize**（意识到/实现，动词）

#### ④ 副词后缀（→ 副词 adverb）

| 后缀 | 作用 | 例子 |
|---|---|---|
| -ly | "…地"（多由形容词变来） | quick→quickly 快速地、happy→happily 快乐地 |

**中英对照案例**：
1. quick（快的）→ quick**ly**（快速地）
2. happy（快乐的）→ happi**ly**（快乐地，注意 y 变 i 加 ly）

**易错误区**：
- 后缀有固定搭配，不能随意创造：happy 的副词是 happi**ly**（变 y 为 i），happyly 是错的；
- 同一个词尾多数固定对应一种词性（如 -ness/-tion 是名词、-ful/-ous 是形容词、-ly 常是副词），但个别有例外，遇到时以"它前面有没有 the / 是不是在 be 后面"等句子位置来二次确认；
- 有少数词很相似易混：like（喜欢，动词）vs likely（可能，形容词）vs alike（相似的）——词尾帮你初判，上下文帮你定案。

## 合成词与合成名词复数

> **速查结论：**classroom、good-looking等是合成；passers-by等复数看具体结构。

### 规则、例句与使用边界

**合成法（compounding）= 把两个或多个独立的单词拼接在一起，构成一个新词。**

**核心规则**：可构成合成名词、合成形容词、合成动词。

**中英对照案例**：
1. class + room → **classroom** 教室（合成名词）
2. good + looking → **good-looking** 好看的（合成形容词）
3. white + wash → **whitewash** 粉刷（合成动词）

**核心分类**：

| 类型 | 例子 |
|---|---|
| 合成名词 | classroom、raincoat（雨衣）、football（足球） |
| 合成形容词 | good-looking、hard-working、warm-hearted |
| 合成动词 | whitewash、sunbathe（日光浴） |

**易错误区**：
- 合成名词的复数一般变**主体名词**：passer-by → **passers-by**，mother-in-law → **mothers-in-law**，不能说 passer-bys；
- 合成形容词一般加连字符：good-looking。

## 词类转化

> **速查结论：**词不加显式词缀也能换词类用法，转化后的动词仍遵守相应动词形式。

### 规则、例句与使用边界

**转化法（conversion）= 一个单词不改变拼写，直接从一种词性转化为另一种词性。**

**核心规则**：常见名词转动词、形容词转动词、动词转名词。

**中英对照案例**：
1. water（水，名词）→ to **water** flowers 浇花（动词）
2. clean（干净的，形容词）→ to **clean** the room 打扫房间（动词）
3. swim（游泳，动词）→ have a **swim** 游一次泳（名词）

**核心分类**：

| 转化 | 例子 |
|---|---|
| 名词 → 动词 | water（水→浇水）、book（书→预订） |
| 形容词 → 动词 | clean（干净→打扫）、warm（温暖→使变暖） |
| 动词 → 名词 | swim（游泳→一次游泳）、look（看→外观） |

**易错误区**：转化后的动词语义和原名词相关，不能随意引申：water 是"浇水"，不是"与水有关的一切动作"。

## 缩略词

> **速查结论：**截短和首字母缩略不同；读字母还是读成单词须按实际词学习。

### 规则、例句与使用边界

**缩略法（abbreviation）= 把长单词、长短语缩短或取首字母，构成新词，意思不变。**

**核心规则**：
1. 截短词：截取单词一部分；
2. 首字母缩写词：取每个单词首字母。

**中英对照案例**：
1. examination → **exam** 考试（截短词）
2. World Health Organization → **WHO** 世界卫生组织（首字母缩写）
3. television → **TV** 电视

**核心分类**：

| 类型 | 例子 |
|---|---|
| 截短词 | exam（examination）、phone（telephone）、ad（advertisement） |
| 首字母缩写 | WHO、UFO（不明飞行物）、VIP（重要人物） |

**易错误区**：
- 首字母缩写词读音分两种：字母拼读（UFO 一个字母一个字母读）和单词拼读（NASA 按单词读）；
- 首字母缩写是否加 the 要看是否专有：the WHO 常有 the，但要看具体用法。
