## 条件假设

### 真实条件与非真实条件

> **速查结论：**先看说话者把情况视为现实可能、较远假设还是过去反事实，别见if就统一变虚拟。

#### 规则、例句与使用边界

**虚拟语气（subjunctive mood）= 表达与事实相反的假设、无法实现的愿望、建议要求等非真实情况。**

一句话记住：**先区分真实条件、远离现实的假设、遗憾以及建议要求；这些结构不都靠机械“时态后退”来构造。**

**中英对照案例**：
1. If I **were** you, I **would study** harder. 如果我是你，我会更努力学习。（我不是你，事实相反）
2. I **wish** I **were** a bird. 我希望我是一只鸟。（我不是鸟，无法实现）
3. He suggested that we **read** more books. 他建议我们多读书。（建议，should 省略）

**核心规则**：
1. 虚拟语气里 **非真实假设中的 be 正式表达通常用 were**（包括 I、he、she）；
2. 主句和从句的时态要**配合**（对应后退）。

**核心规则**：

| 时间 | if 从句 | 主句 | 例子 |
|---|---|---|---|
| 现在 | 一般过去时（were） | would + 原形 | If I were you... |
| 过去 | had done | would have done | If I had known... |
| 将来 | were to do / should do | would + 原形 | If it should rain... |

### 现在非真实条件句

> **速查结论：**if加过去形式，结果常用would/could等加原形；过去形式不必指实际过去。

#### 规则、例句与使用边界

**通俗定义**：假设和现在现实相反的情况。

**核心规则**：
1. if 从句：一般过去时（be 动词用 were）；
2. 主句：would/could/should/might + 动词原形。

**中英对照案例**：
1. If I **were** you, I **would study** harder. 如果我是你，我会更努力学习。
2. If I **had** time, I **would go** with you. 如果我有时间，我就和你一起去。
3. If I **knew** the answer, I **would tell** you. 如果我知道答案，我会告诉你。

**易错误区**：非真实假设中，正式表达通常用 were；非正式用法也可见 was。优先掌握 If I were you。

### 过去反事实条件句

> **速查结论：**if加had done，结果常用would/could等加have done。

#### 规则、例句与使用边界

**通俗定义**：假设和过去已经发生的事实相反，表后悔、遗憾。

**核心规则**：
1. if 从句：had + 过去分词；
2. 主句：would/could/should/might + have + 过去分词。

**中英对照案例**：
1. If I **had known** the truth, I **would have told** you. 如果我当时知道真相，我就告诉你了。
2. He **would have passed** the exam if he **had worked** harder. 如果他更努力，就通过考试了。

**易错误区**：主句和从句时态要对应，不能混搭错误。

### 将来非真实条件句

> **速查结论：**过去形式、were to、should等可构成不同的未来假设，不对应固定概率。

#### 规则、例句与使用边界

**通俗定义**：假设将来不太可能发生的事情，可能性很低。

**核心规则**：
1. if 从句：一般过去时 / were to do / should + 动词原形；
2. 主句：would/could/should/might + 动词原形。

**中英对照案例**：
1. If it **should rain** tomorrow, we **would put off** the match. 万一明天下雨，我们就推迟比赛。
2. If I **were to do** it, I **would do** it differently. 要是我来做，我会用不同方法。

**易错误区**：这类假设表示说话者把情况看得较不确定或较远离现实，不对应固定概率；过去形式也能表达对现在或未来的假设。

### 混合条件句

> **速查结论：**主从两部分的时间参照可不同，各用适合自己的形式。

#### 规则、例句与使用边界

**通俗定义**：从句和主句时间不一致时，各自用相应的虚拟形式。

**中英对照案例**：
1. If I **had studied** hard, I **would be** a doctor now. 如果我当初努力学习，现在就是医生了。（从句过去，主句现在）
2. If he **were** taller, he **would have been** chosen. 如果他高点，当初就会被选上了。（从句现在，主句过去）

**易错误区**：混合虚拟要判断主从句各自的时间参照，不能机械套用一种形式。

### 含蓄条件句

> **速查结论：**条件可由短语或上下文给出，不能只按有没有if识别假设。

#### 规则、例句与使用边界

**没有 if 引导的条件句，用介词短语、上下文等暗示虚拟条件。**

**核心规则**：常用 but for、without、otherwise 等暗示条件。

**中英对照案例**：
1. **Without** your help, I couldn't have succeeded. 没有你的帮助，我不可能成功。（= If I hadn't had your help）
2. **But for** the rain, we would have had a nice trip. 要不是下雨，我们的旅行会很愉快。
3. I was busy; **otherwise**, I would have come. 我当时很忙；否则我就来了。

**易错误区**：要根据语境判断是真实还是虚拟，不能只看结构。

### 虚拟条件句的省 if 倒装

> **速查结论：**满足相应结构时省if并提前相关形式，不写If had I known。

#### 规则、例句与使用边界

**通俗定义**：if 从句中含 were/had/should 时，可省略 if，把该词提前。

**中英对照案例**：
1. **Had** I known, I would have come. 我要是知道，就来了。（= If I had known）
2. **Should** it rain, we would stay at home. 万一下雨，我们就待在家。（= If it should rain）
3. **Were** I you, I would accept it. 如果我是你，我会接受。（= If I were you）

**易错误区**：倒装后 if 必须省略，不能说 If had I known。

## 愿望与建议结构

### wish、if only 虚拟结构

> **速查结论：**过去形式常表达现在愿望，过去完成表达过去遗憾，would可表达希望发生变化等。

#### 规则、例句与使用边界

**wish 表与现实相反或无法实现的愿望；if only 表"要是……就好了"。**

**核心规则**：
1. 对现在虚拟：wish + 一般过去时（be 用 were）；
2. 对过去虚拟：wish + had done；
3. 对将来虚拟：wish + would/could + 动词原形。

**中英对照案例**：
1. I **wish** I **were** a bird. 我希望我是一只鸟。（现在）
2. He **wishes** he **had studied** harder. 他希望当初更努力学习。（过去）
3. I **wish** it **would stop** raining. 我希望雨能停。（将来）

**易错误区**：本节 wish + 从句表达非真实愿望时，通常用过去式表示现在，用过去完成表示过去；不要把这条推广到所有 wish 用法，如 I wish you well、I wish to leave；if only 用法与 wish 相同：If only I had known!（我要是早知道就好了！）

### 建议、命令与要求从句的虚拟形式

> **速查结论：**表示建议要求时可用(should)加原形；表示表明或坚持事实时另按实际意义。

#### 规则、例句与使用边界

**在表示建议、命令、要求、愿望的名词性从句中，使用虚拟语气（should + 动词原形，should 常省略）。**

**核心规则**：
1. 从句谓语用 should + 动词原形，should 可以省略；
2. 适用于 suggest、order、demand、insist、advise、recommend 等动词后的宾语从句，以及相关的表语从句、主语从句。

**中英对照案例**：
1. The teacher suggested that we **(should) read** more books. 老师建议我们多读书。
2. His demand is that we **(should) finish** the work on time. 他要求我们按时完成工作。
3. It is important that you **(should) be** on time. 你准时很重要。

**易错误区**：
- suggest 表"暗示、表明"时不用虚拟，用真实语气：The look on his face suggested that he **was** angry.（暗示，真实语气）
- insist 表"坚持认为"（事实）时不用虚拟，表"坚持要求"时用虚拟。

### would rather、It's time 虚拟结构

> **速查结论：**would rather接从句与接原形有别；It's time的过去形式不等于过去发生。

#### 规则、例句与使用边界

**would rather 表"宁愿"、It's (high) time 表"该做……了"，后接从句时用虚拟。**

**核心规则**：
1. would rather + 从句：用一般过去时（对现在/将来），had done（对过去）；
2. It's (high/about) time + that 从句：用一般过去时或 should + 动词原形。

**中英对照案例**：
1. I'd rather you **came** tomorrow. 我宁愿你明天来。
2. I'd rather you **hadn't said** that. 我宁愿你没说过那话。
3. It's time we **went** home. 我们该回家了。
4. It's high time you **should start** working. 你该开始工作了。

**易错误区**：
- It's time 后用过去式表虚拟，不是真的过去；
- would rather 后面跟动词原形是"宁愿自己做"（I'd rather go），跟从句时才是虚拟。

### as if、as though 的陈述与虚拟形式

> **速查结论：**看说话者是否认为情况真实或合理可能，不把as if后的每种时态都机械后退。

#### 规则、例句与使用边界

**as if/as though 表"好像、仿佛"，其后常用虚拟语气（尤其在正式书面语中）。**

**核心规则**：
1. 对现在虚拟：as if + 一般过去时（be 用 were）；
2. 对过去虚拟：as if + had done。

**中英对照案例**：
1. He talks **as if he knew** everything. 他说起话来好像什么都知道。（现在）
2. She looked **as if she had cried**. 她看起来好像哭过。（过去）

**易错误区**：口语中 as if 后也可用真实语气（It looks as if it is going to rain），但正式表达多用虚拟。
