## 七个月首轮题单

题目标记中的“选做”只表示本轮训练安排，不表示知识点从未考过。“识读必做”仍需理解并作答。

- **分项必做：**A01、A02、A03、A04、A05、A06、A07、A08、A17、A18、A19、A20、A21、A22、A23、A24。
- **串联必做：**B01、B02、B03、B04。
- **补练必做：**无。
- **验收必做：**C01、C02、C03、C04、C05、C06、C07、C08、C09、C10、C11、C12。

先做以上题目。首轮C按实际必做题计算，满分24分，建议至少20分；得分后仍要修正错题与不稳项。A、B、D中的必做题能独立完成并说明题干要求的理由即可，不再要求把选做题刷完才能继续。

若A的某个情境不稳，再做同情境标为选做的改错题；只针对卡点加练。原有全卷与完整复习标准保留在文末，供第二轮使用。

## A 分项强化

**A01｜【必做】主格宾格**　按提示补全或完成（写完整句子或短语）：___ likes me.（她）

**A02｜【必做】宾格**　按提示补全或完成（写完整句子或短语）：Tom helps ___.（我）

**A03｜【必做】所属限定**　按提示补全或完成（写完整句子或短语）：This is ___ book.（我的）

**A04｜【必做】名词性所属**　按提示补全或完成（写完整句子或短语）：This book is ___.（她的）

**A05｜【必做】反身**　按提示补全或完成（写完整句子或短语）：She helps ___.（她自己）

**A06｜【必做】指示复数**　按提示补全或完成（写完整句子或短语）：___ are books.（这些）

**A07｜【必做】远指**　按提示补全或完成（写完整句子或短语）：___ is my book.（那个）

**A08｜【必做】相互**　按提示补全或完成（写完整句子或短语）：They help ___.（彼此）

**A09｜【选做】主格宾格**　目标意思：她喜欢我。 请修正不合形式或不合题意的表达：`Her likes me.`。

**A10｜【选做】宾格**　目标意思：汤姆帮助我。 请修正不合形式或不合题意的表达：`Tom helps I.`。

**A11｜【选做】所属限定**　目标意思：这是我的书。 请修正不合形式或不合题意的表达：`This is mine book.`。

**A12｜【选做】名词性所属**　目标意思：这本书是她的。 请修正不合形式或不合题意的表达：`This book is her.`。

**A13｜【选做】反身**　目标意思：她帮助她自己。 请修正不合形式或不合题意的表达：`She helps himself.`。

**A14｜【选做】指示复数**　目标意思：这些是书。 请修正不合形式或不合题意的表达：`This are books.`。

**A15｜【选做】远指**　目标意思：那是我的书。 请修正不合形式或不合题意的表达：`Those is my book.`。

**A16｜【选做】相互**　目标意思：他们互相帮助。 请修正不合形式或不合题意的表达：`They help each other's.`。

**A17｜【必做】主格宾格**　独立表达：她喜欢我。 可用词语（次序打乱，不要求全部唯一用法）：likes / me / She。

**A18｜【必做】宾格**　独立表达：汤姆帮助我。 可用词语（次序打乱，不要求全部唯一用法）：helps / me / Tom。

**A19｜【必做】所属限定**　独立表达：这是我的书。 可用词语（次序打乱，不要求全部唯一用法）：book / is / my / This。

**A20｜【必做】名词性所属**　独立表达：这本书是她的。 可用词语（次序打乱，不要求全部唯一用法）：book / hers / is / This。

**A21｜【必做】反身**　独立表达：她帮助她自己。 可用词语（次序打乱，不要求全部唯一用法）：helps / herself / She。

**A22｜【必做】指示复数**　独立表达：这些是书。 可用词语（次序打乱，不要求全部唯一用法）：are / books / These。

**A23｜【必做】远指**　独立表达：那是我的书。 可用词语（次序打乱，不要求全部唯一用法）：book / is / my / That。

**A24｜【必做】相互**　独立表达：他们互相帮助。 可用词语（次序打乱，不要求全部唯一用法）：each / help / other / They。

## C 独立验收

先关闭本章、A/B答案，独立作答。完整12题每题2分，共24分；七个月首轮只计算上方必做题，满分24分、建议至少20分。选做题不进入首轮分母。这是自学建议，不是标准化等级考试。

**C01｜【必做】宾格**　补全：We help ___.（他们）

**C02｜【必做】主格**　补全：___ help us.（他们）

**C03｜【必做】物主**　把your pen改成不再重复pen的所属形式。

**C04｜【必做】物主**　补全：The house is ___.（我们的）

**C05｜【必做】反身**　“我独自”写成by ...短语。

**C06｜【必做】反身**　改正：Myself am happy.

**C07｜【必做】指示**　those books对应近指复数是什么？

**C08｜【必做】疑问代词**　“谁是她的老师？”中的“谁”，从who／whose／what中选对应词；不要求写出整个英文问句。

**C09｜【必做】相互**　“两人互相帮助”能用each other吗？

**C10｜【必做】宾格**　改正：She likes we.

**C11｜【必做】反身**　Tom makes the toy himself中himself表达什么意思？

**C12｜【必做】限定与替代**　my、mine能互换填入同一位置吗？举出一组。

## 验收标准与错题修复

**七个月首轮：**C必做题至少20/24；A、B、D中的必做项能够独立完成，错题和不稳项能说明题干要求的理由。标为选做的题不作为继续条件。

**第二轮完整复习：**下面保留原全量训练标准；它不覆盖或撤销上面的首轮题单。

- **可以继续：**C达到20/24分，A的24题至少20题能独立完成，B至少3题会做；C中的表达题能说明自己写法的核心理由。不能用“刚看答案后抄对”计入独立完成。
- **需要巩固：**C为16—19分，或某个核心情境的三种任务中连续错两题。按上表标签回到正文对应小节，解释错因后重做同标签的A题，再用自己的词写一个同结构例子。
- **先修复再继续：**C低于16分，或只能认选项、无法完成基本表达。先回本章，处理错得最多的两个标签；不要求盲目刷完整卷第二遍。
- **延迟复测：**隔一天先不看答案，重做错过的C题，再重做A中相应的表达题。复测沿用已有题，不另算新增题量；能够解释并改对再进入下一章。
