**E20｜【选做】虚拟语气选择**　But for the rain, we ______ a nice trip. (would have had / had / have)（句意：要不是下雨，我们那次旅行会很愉快。）

**E21｜【选做】虚拟语气选择**　I was busy; otherwise, I ______ come. (would have / would / will)（句意：我当时很忙；否则我就来了。）

**E22｜【选做】虚拟语气选择**　The teacher insisted that we ______ on time. (be / are / were)（句意：老师坚持要求我们准时。）

**E23｜【选做】虚拟语气选择**　If you had come earlier, you ______ her. (would meet / would have met / meet)（句意：如果你当时早点来，你就会见到她了。）

**E24｜【选做】虚拟语气选择**　It is important that you ______ careful. (be / are / was)（句意：你小心一点很重要；要求用本章介绍的原形虚拟结构。）

**E25｜【选做】虚拟语气选择**　I'd rather you ______ that. (hadn't said / don't say / didn't say)（句意：我宁愿你当初没说过那话；对过去。）

<details>
<summary>完成本组后再展开答案与解析</summary>
<p><strong>E01</strong>　were（本题指定正式假设形式）；非正式语境也可见 was，不能笼统判为所有英语中都错。</p>
<p><strong>E02</strong>　had（对现在虚拟，if 从句用过去式）。</p>
<p><strong>E03</strong>　would have told（对过去虚拟，主句 would have done）。</p>
<p><strong>E04</strong>　had worked（对过去虚拟，从句 had done）。</p>
<p><strong>E05</strong>　should rain 或 rained。两者都能表达相应的未来假设；前者可突出偶然发生的条件，后者是常见过去形式假设。</p>
<p><strong>E06</strong>　couldn't have（含蓄虚拟，without）。</p>
<p><strong>E07</strong>　read（suggest + (should) 原形）。</p>
<p><strong>E08</strong>　finish（demand + (should) 原形）。</p>
<p><strong>E09</strong>　were（本题指定正式形式）；非正式用法也可见 was。</p>
<p><strong>E10</strong>　had studied（本题对过去遗憾）；若表达对现在学习状态的不满，可说 He wishes he studied harder。</p>
<p><strong>E11</strong>　came（would rather + 过去式）。</p>
<p><strong>E12</strong>　went（It's time + 过去式）。</p>
<p><strong>E13</strong>　Had（虚拟倒装）。</p>
<p><strong>E14</strong>　Should（虚拟倒装）。</p>
<p><strong>E15</strong>　would be（混合虚拟，主句对现在）。</p>

<p><strong>E17</strong>　had cried（按题目要求，用过去完成形式表示相对过去的先发生）。</p>
<p><strong>E18</strong>　would（wish 对将来虚拟）。</p>
<p><strong>E19</strong>　were（对将来虚拟，were to do）。</p>

<p><strong>E22</strong>　be（insist 坚持要求 + (should) 原形）。</p>
<p><strong>E23</strong>　would have met（对过去虚拟）。</p>
<p><strong>E24</strong>　be（本题指定原形虚拟结构；也可用 should be）；其他语体中存在陈述式表达，不能把所有 are 都判为不合语法。</p>

## F 随堂练习与通关自检

本组来自正文迁移的“根据语境选择虚拟语气”随堂练习与“合上书自检”；标为选做，不计入首轮验收分母。

**F01｜【选做】随堂练习**　用给定词写句：`if / I / have more time / would read more`，表达与现在不同的假设。

**F02｜【选做】随堂练习**　对照解释 *I wish I studied harder* 与 *I wish I had studied harder*。

**F03｜【选做】随堂练习**　写一句现在或将来的真实条件。

**F04｜【选做】通关自检**　对现在、对过去的 `if` 虚拟条件句，从句和主句各用什么动词形式？

**F05｜【选做】通关自检**　*The teacher suggested that we ___ (read) more.* 和 *His smile suggested that he ___ (be) happy.* 为什么一个用原形、一个用过去式？

**F06｜【选做】通关自检**　看到 *Had I studied harder, I would be a doctor now.*，怎么还原 `if` 并判断主从句时间？

<details>
<summary>完成本组后再展开答案与解析</summary>
<p><strong>F01</strong>　If I had more time, I would read more.</p>
<p><strong>F02</strong>　前者通常希望现在更用功；后者遗憾过去没更用功。</p>
<p><strong>F03</strong>　示例：If it rains tomorrow, I will stay at home. 不是所有 if 句都用同一假设结构。</p>
<p><strong>F04</strong>　对现在：从句用过去式（<code>were</code>），主句用 <code>would + 原形</code>；对过去：从句用 <code>had done</code>，主句用 <code>would have done</code>。</p>
<p><strong>F05</strong>　前者 <code>suggest</code> 表“建议”，用 <code>(should) read</code>；后者表“暗示/表明”，用真实语气 <code>was</code>。</p>
<p><strong>F06</strong>　还原为 <code>If I had studied harder, I would be a doctor now.</code>，属于混合虚拟：从句假设过去，主句说明现在结果。</p>
</details>
