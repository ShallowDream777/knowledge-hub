**A14｜【选做】强调时间**　目标意思：他是昨天来的，要求本章强调句型。 请修正不合形式或不合题意的表达：`It was yesterday when he came.`。

**A15｜【选做】动词强调**　目标意思：她确实通过了考试。 请修正不合形式或不合题意的表达：`She did passed the exam.`。

**A17｜【必做】否定倒装**　独立表达：我以前从未见过这个。 可用词语（次序打乱，不要求全部唯一用法）：before / have / I / Never / seen / this。

**A19｜【选做】地点倒装**　独立表达：公交车来了。 可用词语（次序打乱，不要求全部唯一用法）：bus / comes / Here / the。

**A20｜【选做】代词不倒装**　独立表达：它在这里。 可用词语（次序打乱，不要求全部唯一用法）：Here / is / it。

**A21｜【必做】强调人**　独立表达：是埃米帮助了我。 可用词语（次序打乱，不要求全部唯一用法）：Amy / helped / It / me / was / who。

**A22｜【必做】强调时间**　独立表达：他是昨天来的，要求本章强调句型。 可用词语（次序打乱，不要求全部唯一用法）：came / he / It / that / was / yesterday。

**A23｜【必做】动词强调**　独立表达：她确实通过了考试。 可用词语（次序打乱，不要求全部唯一用法）：did / exam / pass / She / the。

## C 独立验收

先关闭本章、A/B答案，独立作答。完整12题每题2分，共24分；七个月首轮只计算上方必做题，满分20分、建议至少16分。选做题不进入首轮分母。这是自学建议，不是标准化等级考试。

**C01｜【必做】还原**　把Never have I seen it还原普通语序。

**C02｜【必做】only主语**　Only Amy knows，是否必须倒成Only does Amy know？

**C03｜【必做】倒装过去**　纠正So loudly did he spoke that we heard him。

**C04｜【必做】名词强调**　强调普通句Tom read this book中的this book。

**C05｜【必做】强调省略**　It was Tom I met在非正式表达中一定因缺that而错吗？

**C06｜【必做】省略条件**　When tired, I rest中省略了哪些内容？

**C07｜【必做】固定省略**　If necessary, ask Amy能因主从主语不一致就判错吗？

**C08｜【必做】比较省略**　He runs faster than I do中的do承接什么？

**C09｜【选做】让步倒装**　把Although he is young, he is wise用Young ... as结构表达。

**C10｜【选做】名词让步**　按本章结构补全：___ as he is, he is brave.（child，孩子）

**C11｜【必做】不定式保留**　对Would you like to come?给出愿意的省略回答。

**C12｜【必做】开放**　写一对普通句和强调句，强调对象须是人或时间。

## 验收标准与错题修复

**七个月首轮：**C必做题至少16/20；A、B、D中的必做项能够独立完成，错题和不稳项能说明题干要求的理由。标为选做的题不作为继续条件。

**第二轮完整复习：**下面保留原全量训练标准；它不覆盖或撤销上面的首轮题单。

- **可以继续：**C达到20/24分，A的24题至少20题能独立完成，B至少3题会做；C中的表达题能说明自己写法的核心理由。不能用“刚看答案后抄对”计入独立完成。
- **需要巩固：**C为16—19分，或某个核心情境的三种任务中连续错两题。按上表标签回到正文对应小节，解释错因后重做同标签的A题，再用自己的词写一个同结构例子。
- **先修复再继续：**C低于16分，或只能认选项、无法完成基本表达。先回本章，处理错得最多的两个标签；不要求盲目刷完整卷第二遍。
- **延迟复测：**隔一天先不看答案，重做错过的C题，再重做A中相应的表达题。复测沿用已有题，不另算新增题量；能够解释并改对再进入下一章。
