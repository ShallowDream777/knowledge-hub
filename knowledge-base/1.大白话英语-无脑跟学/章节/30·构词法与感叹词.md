### 构词法与词形变化：新词和同一词的不同形式　【必学】

先分清两种常见变化：
- **词形变化**：`book → books` 仍是“书”这个词的数量变化，没有造出新词。
- **构词法**：`teach → teacher` 形成了表示“老师”的新词。

构词法中最常借助的是“词缀”：
- **前缀**加在词前，如 `un + happy → unhappy`；
- **后缀**加在词后，如 `teach + er → teacher`；
- **词根**指承载主要意义的基础部分。

> 提示：构词法能帮你快速识别词族、合理猜词，但不能靠一个熟悉词尾保证所有生词都猜对，实际含义仍要结合语境核对。

---

### 什么是构词法　【必学】

#### 通俗定义

==**构词法（word formation）** = 英语造新词的规律，主要有四种：派生法、合成法、转化法、缩略法==。

**中英对照案例**：
1. `happy`（开心）→ **`un`happy**（不开心）（派生：加前缀）
2. `teach`（教）→ **teach`er`**（老师）（派生：加后缀）
3. `class` + `room` → **`classroom`**（教室）（合成：两个词拼接）
4. `water`（水，名词）→ to **`water`** flowers（浇花，动词）（转化：名词变动词）

---

### 派生法（最常用）　【必学】

#### 通俗定义

**派生法（derivation）** = 在词根前面加前缀，或在后面加后缀，构成新词。

**核心规则**：
1. ==前缀一般改变词义==，不改变词性（如 `happy` → `unhappy` 仍是形容词）。
2. ==后缀一般改变词性==，不改变核心词义（如 `teach` 动词 → `teacher` 名词）。

#### 1. 常用前缀（高频阅读拓展表）

| 前缀 | 核心含义 | 高频例子 |
|---|---|---|
| `un-` | 不、非 | `happy → unhappy`（不开心的）、`kind → unkind`（不友善的） |
| `dis-` | 不、相反 | `agree → disagree`（不同意）、`like → dislike`（不喜欢） |
| `im- / in- / ir- / il-` | 不、非 | `possible → impossible`（不可能的）、`correct → incorrect`（不正确的）、`regular → irregular`（不规则的）、`legal → illegal`（非法的） |
| `non-` | 非、无 | `stop → nonstop`（不停的）、`smoking → nonsmoking`（禁烟的） |
| `mis-` | 错误地、误 | `understand → misunderstand`（误解）、`mistake`（错误） |
| `re-` | 再、重新 | `write → rewrite`（重写）、`build → rebuild`（重建） |
| `pre-` | 预先、在……之前 | `view → preview`（预习/预览）、`school → preschool`（学龄前的） |
| `over-` | 过度、在……之上 | `work → overwork`（过度劳累）、`sleep → oversleep`（睡过头） |
| `under-` | 不足、在……之下 | `ground → underground`（地下的）、`line → underline`（在……下画线） |
| `inter-` | 相互、在……之间 | `national → international`（国际的）、`net → Internet`（互联网） |
| `sub-` | 在……下、次级 | `way → subway`（地铁）、`title → subtitle`（副标题/字幕） |
| `super-` | 超级、在……之上 | `market → supermarket`（超市）、`star → superstar`（巨星） |
| `anti-` | 反对、抗 | `virus → antivirus`（防病毒的）、`social → antisocial`（反社会的） |
| `multi-` | 多、多种 | `media → multimedia`（多媒体）、`cultural → multicultural`（多元文化的） |
| `co-` | 共同、一起 | `worker → coworker`（同事）、`operate → cooperate`（合作） |

> [!warning] 易错避坑
> - 否定前缀有固定搭配，**不能随意混用**：`unhappy`、`impossible`、`illegal` 都是固定搭配，❌ `imhappy`、❌ `unpossible` 都是错的。

#### 2. 常见后缀及其对应词类

> **为什么按词性分类最有价值**：背单词或做阅读时，只要记住“看到某个词尾多半是名词 / 形容词 / 副词”，再结合它在句中的位置，就能很快判断词性。

##### ① 名词后缀（→ 名词 noun）

| 后缀 | 作用 | 例子 |
|---|---|---|
| `-er / -or` | 表“人 / 做某事的人” | `teach → teacher` 老师、`act → actor` 演员 |
| `-tion / -sion` | 表动作/状态的结果（常由动词变来） | `educate → education` 教育、`decide → decision` 决定 |
| `-ness` | 表性质/状态（常由形容词变来） | `happy → happiness` 幸福、`kind → kindness` 善良 |
| `-ment` | 表动作/结果（常由动词变来） | `develop → development` 发展、`agree → agreement` 同意 |
| `-ity / -ty` | 表性质/状态（常由形容词变来） | `real → reality` 现实、`safe → safety` 安全 |
| `-ance / -ence` | 表状态/性质（常由动词或形容词变来） | `important → importance` 重要、`differ → difference` 不同 |
| `-th` | 表性质/状态（常由形容词变来） | `true → truth` 真相、`warm → warmth` 温暖 |
| `-ist` | 表“做……的人 / 专家” | `art → artist` 艺术家、`science → scientist` 科学家 |
| `-ship` | 表身份/状态/关系 | `friend → friendship` 友谊、`leader → leadership` 领导力 |

> 常见名词转换高频组：`decide → decision`、`educate → education`、`develop → development`、`agree → agreement`、`happy → happiness`、`kind → kindness`。

##### ② 形容词后缀（→ 形容词 adjective）

| 后缀 | 作用 | 例子 |
|---|---|---|
| `-ful` | “充满……的” | `care → careful` 细心的、`use → useful` 有用的 |
| `-less` | “没有……的” | `care → careless` 粗心的、`use → useless` 没用的 |
| `-y` | “多……的” | `sun → sunny` 晴朗的、`rain → rainy` 多雨的 |
| `-ous` | “……的” | `danger → dangerous` 危险的、`fame → famous` 著名的 |
| `-al` | “……的 / 与……有关” | `nation → national` 国家的、`nature → natural` 自然的 |
| `-ive` | “……性的 / 有……倾向” | `act → active` 积极的、`create → creative` 有创造力的 |
| `-able / -ible` | “能……的 / 可……的” | `read → readable` 可读的、`enjoy → enjoyable` 令人愉快的 |
| `-ic` | “……的 / 与……相关” | `base → basic` 基本的、`science → scientific` 科学的 |

##### ③ 动词后缀（→ 动词 verb）

| 后缀 | 作用 | 例子 |
|---|---|---|
| `-ize / -ise` | “使……化” | `real → realize` 实现/意识到、`modern → modernize` 使现代化 |
| `-en` | “使变得……” | `wide → widen` 加宽、`short → shorten` 缩短 |
| `-ify` | “使……化 / 使成为” | `simple → simplify` 简化、`beauty → beautify` 美化 |

##### ④ 副词后缀（→ 副词 adverb）

| 后缀 | 作用 | 例子 |
|---|---|---|
| `-ly` | “……地”（多由形容词变来） | `quick → quickly` 快速地、`happy → happily` 快乐地（`y` 变 `i` 加 `ly`） |

> [!warning] 易错避坑
> - 拼写变化要留心：`happy → happily` / `happiness`（变 `y` 为 `i`），❌ `happyly` / ❌ `happyness` 都是错的。
> - 词尾只提供第一眼线索，少数词有例外（如 `friendly` 是形容词而不是副词），遇到时要结合句中位置（是否在 `the` 后、是否在 `be` 后）二次确认。
> - 形近易混词：`like`（喜欢，动词）vs `likely`（可能的，形容词）vs `alike`（相似的）。

> [!important] 记笔记
> - ==前缀改意思，后缀改词性==。
> - 看到 `-tion / -ness / -ment / -er` 多半是**名词**；`-ful / -less / -ous / -al / -able` 多半是**形容词**；`-ize / -en / -ify` 多半是**动词**；`-ly` 多半是**副词**。

### 合成法　【识读即可】

> 看懂熟悉词如何组合成整体意思；特殊合成复数与连字符先按词识别，不反复套规则造词。普通名词复数仍必学。

#### 通俗定义

**合成法（compounding）** = 把两个或多个独立的单词拼接在一起，构成一个新词。

| 类型 | 例子 |
|---|---|
| 合成名词 | `classroom`（教室）、`raincoat`（雨衣）、`football`（足球） |
| 合成形容词 | `good-looking`（好看的）、`hard-working`（勤奋的）、`warm-hearted`（热心的） |
| 合成动词 | `whitewash`（粉刷）、`sunbathe`（晒日光浴） |

> [!warning] 易错避坑
> - 合成名词变复数一般变**主体名词**：`passer-by → passers-by`（过路人）、`mother-in-law → mothers-in-law`（岳母/婆婆），不能说 ❌ `passer-bys`。
> - 作前置定语的合成形容词通常加连字符：`a good-looking boy`。

---

### 转化法　【必学】

#### 通俗定义

==**转化法（conversion）** = 一个单词不改变拼写，直接从一种词性转化为另一种词性==。

| 转化方向 | 例子 |
|---|---|
| 名词 → 动词 | `water`（水 → 浇水 *to water flowers*）、`book`（书 → 预订 *to book a ticket*） |
| 形容词 → 动词 | `clean`（干净的 → 打扫 *to clean the room*）、`warm`（温暖的 → 使变暖） |
| 动词 → 名词 | `swim`（游泳 → *have a swim* 游一次泳）、`look`（看 → *have a look* 看一看） |

> 提示：转化后的动词语义与原词密切相关，不能随意引申（`water` 转化后是“浇水”，不是“与水有关的一切动作”）。

---

### 缩略法　【识读即可】

> 看懂常用截短和首字母缩写即可，不背每个缩写的完整展开。2025题面有AI、ABS和fMRI。

#### 通俗定义

**缩略法（abbreviation）** = 把长单词、长短语缩短或取首字母，构成新词，意思不变。

| 类型 | 规则 | 例子 |
|---|---|---|
| 截短词 | 截取单词一部分 | `exam`（`examination`）、`phone`（`telephone`）、`ad`（`advertisement`） |
| 首字母缩写 | 取每个单词首字母 | `WHO`（World Health Organization）、`UFO`（不明飞行物）、`VIP`（重要人物）、`TV`（`television`） |

> 提示：
> - 首字母缩写读音分两种：逐字母读（如 `UFO`、`VIP`）和按单词读（如 `NASA`）。
> - 专有缩写前是否加 `the` 按惯用名称判断：常说 `the UN`、`the WHO`，但 `NASA` 前不加 `the`。

---

### 感叹词　【识读即可】

> 能理解 `Oh` / `Wow` 等在对话中的反应，不要求背诵或列举冷僻感叹词。2022口语确实出现 `Wow`。

#### 通俗定义

==**感叹词（interjection）** = 单独用来表达惊讶、喜悦、痛苦、迟疑或打招呼等情绪反应的词或固定短语，不充当句子成分==。

**核心规则**：
1. 常见单词感叹词：`Oh`（哦/噢）、`Ah`（啊）、`Well`（嗯/好吧，口语中常作思考停顿）、`Wow`（哇）、`Ouch`（哎哟）、`Hurray`（好哇）。
2. 常见多词/话语感叹表达：`Come on!`（加油 / 得了吧）、`Excuse me`（打扰一下 / 不好意思）、`Thank goodness!`（谢天谢地！）、`By the way`（顺便说一下）。
3. 感叹词后常用逗号或感叹号与句子隔开，也可单独成句。

**中英对照案例**：
1. **Oh**, what a beautiful view! 哦，多美的景色啊！
2. **Wow**, you look great today! 哇，你今天看起来真棒！
3. **Ouch**, that hurt! 哎哟，那真疼！
4. **Well**, I think so. 嗯，我也这么认为。
5. **Thank goodness**, we caught the bus! 谢天谢地，我们赶上公交车了！

> [!important] 记笔记
> - **感叹词 vs 感叹句**：感叹词（`Wow!`、`Oh`、`Ouch`）是**独立于句法之外的单词或短语**，不作主语/宾语；而**感叹句**（*What a beautiful view!* / *How fast he runs!*）是用 `What / How` 引导的完整句式。

### 附：构词法速查表　【选做·综合复盘】

| 构词法/类别 | 规则 | 例子 |
|---|---|---|
| 派生法 | 前缀改词义、后缀改词性 | `unhappy`、`teacher` |
| 常用前缀 | 否定 `un-/dis-/im-/in-/ir-/il-/non-`；错误 `mis-`；再 `re-`；预 `pre-`；程度/位置 `over-/under-/inter-/sub-/super-`；其他 `anti-/multi-/co-` | `rewrite`、`impossible`、`misunderstand`、`international` |
| 常用后缀 | 名词 `-tion/-ness/-ment/-er/-or`；形容词 `-ful/-less/-ous/-y/-al/-able`；动词 `-ize/-en/-ify`；副词 `-ly` | `education`、`happiness`、`careful`、`quickly` |
| 合成法 | 两个词拼接 | `classroom`、`good-looking` |
| 复合名词复数 | 变主体名词 | `passers-by`、`mothers-in-law` |
| 转化法 | 换词性不换拼写 | `water`（浇水）、`clean`（打扫） |
| 缩略法 | 截短词 / 首字母缩写 | `exam`、`WHO` |
| 感叹词 | 独立表达情绪反应，不作句子成分 | `Oh!`、`Wow!`、`Ouch!`、`Thank goodness!` |

| 关键提醒 | 记忆 |
|---|---|
| 前后缀固定搭配 | 不能随意混用：`impossible` 不是 `unpossible` |
| `-y` 结尾派生 | `happy → happily / happiness`（变 `y` 为 `i`） |
| 复合名词复数 | 变主体名词：`mothers-in-law` |

## 本章核心记忆笔记

**核心必背（只记这几条）**
- ==派生法核心规律：前缀改词义，后缀改词性==（如 `happy → unhappy` 改义，`happy → happiness / happily` 改词性）。
- ==四大高频词性后缀一眼辨认==：名词 `-tion / -ness / -ment / -er`；形容词 `-ful / -less / -ous / -able`；动词 `-ize / -en / -ify`；副词 `-ly`。
- ==转化法不改拼写直接换词性==：`water`（水 → 浇水）、`book`（书 → 预订）、`clean`（干净的 → 打扫）。
- ==合成名词变复数改主体词==：`passer-by → passers-by`、`mother-in-law → mothers-in-law`。
- ==感叹词不充当句子成分==：`Oh`、`Wow`、`Ouch`、`Come on!` 等独立表达情绪反应，不同于 `What / How` 引导的感叹句。

**高频易错避坑**
- ✅ `impossible`（固定前缀 `im-`） vs ❌ `unpossible`
- ✅ `happily` / `happiness`（辅音+`y` 变 `i`） vs ❌ `happyly` / `happyness`
- ✅ `two passers-by`（变主体名词） vs ❌ `two passer-bys`
- ✅ `friendly` 是形容词（友好的） vs ❌ 见 `-ly` 一律当副词
