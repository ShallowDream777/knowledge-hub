# 零基础先修衔接修复

本轮以“读到此处的人已经理解什么、能否按已教步骤作答”为检查口径。原31章文件名和学习顺序保持，增加在使用前的解释，移走初学时不必承担的高级概览，同步修订验收。

## 核心调整

- 第01章重写：字母、词与句子；基础词义与词类；形式与原形；be/am/is/are；简单主语宾语；am/is/are加not。逐词解释具体例句，不再以do/does、三单、宾补、同位语作开篇验收。
- 原先修的八大成分总表移至第10章；高级术语所含知识在第25章归纳。动作否定与三单操作在第11、13章按已解释步骤学习。
- 第02—08章补齐早期例句中使用的数量表达、介词位置、元音声音、音标、音节、重音、拼写双写条件、初步动名词与分数术语。a/an题所需的特殊首音在正文给出，不要求只凭拼写猜不会读的新词。
- 第09—12章补齐公式中的do/doing/done、sb/sth、宾补与SVOC、从句最小概念、否定与提问、普通动作词和名词词尾s的不同作用。I、you不被错误归入“所有单数动词都加s”。
- 第13章先说明动词形式、观察点、for/since与事件／持续状态，再使用它们解释完成结构。完整16格表移至第23章，在各时间组已学完后汇总。
- 第16章以实际的过去推测、未实现评价说明用法；用途被动be used to do的对照放到第17章。第17章先明确to原形与具体see/make等搭配，再使用“被动还原to”说法。
- 第18—31章为各自首次需要的分析方法补接例句。第20章方式从句先使用现实可能的语境；第23章原自测第13题改为已学的过去进行背景，不在第28章之前验收反事实形式。第28章的假设知识保留。
- 第一章与第三章的强化题同步调整；原17组395道自测、31卷1256道强化任务的数量保持，题号和答案配对保留。
- 第05、06、08章原自测共80题补齐中文句意；第06章原第18题不再提前考动词三单，第08章原第22、23题不再提前考第27章的a number of／the number of区别，改为本章已教的百位数与概数；污染状态、到达顺序等例句也改用更直接的已学表达。相关知识仍在原定后续章节保留。

“正文里给过一个名称”不等于“已经教会相关操作”。新桥接按具体例句建立当前判断所需的含义和步骤，不以一句“后面讲”代替前提。音节和首音只使用已提供信息的词；本轮没有把文字语法资料变成完整发音、听力课程。

## 来源与核验

先修说明在`先修衔接.py`维护，在章节目录生成前应用；题目修正在`先修题目.py`维护，由题库导入时应用。`检查先修衔接.py`检查已识别的先修风险，同时继续运行原校订、强化题及折叠答案检查。

修复前文件按字节备份至`先修修复前快照`。为避免Obsidian把同名旧笔记当成学习目录目标，修复前快照与既有内容整改快照中的MD改用`.md.snapshot`扩展名，内容不变；需要恢复时，按原相对路径复制并去掉末尾`.snapshot`。原19份资料与原文快照保持。

读音与拼写边界参考：[British Council：a/an](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/indefinite-article?page=0)、[Cambridge：拼写与双写](https://dictionary.cambridge.org/grammar/british-grammar/plurals)、[Cambridge：音标与重音](https://dictionary.cambridge.org/help/phonetics.html)。这些参考用于核对规则，不要求读者另开页面才能完成本章。
