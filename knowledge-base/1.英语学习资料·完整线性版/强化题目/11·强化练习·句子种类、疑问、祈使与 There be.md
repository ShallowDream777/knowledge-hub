## A 分项强化

**A01｜【必做】be疑问**　按提示补全或完成（写完整句子或短语）：___ she tired?

**A02｜【必做】动作疑问**　按提示补全或完成（写完整句子或短语）：___ he like tea?

**A03｜【必做】动作否定**　按提示补全或完成（写完整句子或短语）：He ___ like tea.

**A04｜【必做】祈使**　按提示补全或完成（写完整句子或短语）：___ the door, please.（open）

**A05｜【必做】否定祈使**　按提示补全或完成（写完整句子或短语）：___ run here.（不要）

**A06｜【必做】存在句单数**　按提示补全或完成（写完整句子或短语）：There ___ a book here.

**A07｜【必做】存在句复数**　按提示补全或完成（写完整句子或短语）：There ___ two books here.

**A08｜【必做】感叹句**　按提示补全或完成（写完整句子或短语）：___ fast he runs!

**A09｜【选做】be疑问**　目标意思：她累吗？ 请修正不合形式或不合题意的表达：`Does she tired?`。

**A10｜【选做】动作疑问**　目标意思：他喜欢茶吗？ 请修正不合形式或不合题意的表达：`Is he like tea?`。

**A11｜【选做】动作否定**　目标意思：他不喜欢茶。 请修正不合形式或不合题意的表达：`He doesn't likes tea.`。

**A12｜【选做】祈使**　目标意思：请开门。 请修正不合形式或不合题意的表达：`Opens the door, please.`。

**A13｜【选做】否定祈使**　目标意思：不要在这里跑。 请修正不合形式或不合题意的表达：`Not run here.`。

**A14｜【选做】存在句单数**　目标意思：这里有一本书。 请修正不合形式或不合题意的表达：`There are a book here.`。

**A15｜【选做】存在句复数**　目标意思：这里有两本书。 请修正不合形式或不合题意的表达：`There is two books here.`。

**A16｜【选做】感叹句**　目标意思：他跑得多快啊！ 请修正不合形式或不合题意的表达：`What fast he runs!`。

**A17｜【必做】be疑问**　独立表达：她累吗？ 可用词语（次序打乱，不要求全部唯一用法）：Is / she / tired。

**A18｜【必做】动作疑问**　独立表达：他喜欢茶吗？ 可用词语（次序打乱，不要求全部唯一用法）：Does / he / like / tea。

**A19｜【必做】动作否定**　独立表达：他不喜欢茶。 可用词语（次序打乱，不要求全部唯一用法）：doesn't / He / like / tea。

**A20｜【必做】祈使**　独立表达：请开门。 可用词语（次序打乱，不要求全部唯一用法）：door / Open / please / the。

**A21｜【必做】否定祈使**　独立表达：不要在这里跑。 可用词语（次序打乱，不要求全部唯一用法）：Don't / here / run。

**A22｜【必做】存在句单数**　独立表达：这里有一本书。 可用词语（次序打乱，不要求全部唯一用法）：a / book / here / is / There。

**A23｜【必做】存在句复数**　独立表达：这里有两本书。 可用词语（次序打乱，不要求全部唯一用法）：are / books / here / There / two。

**A24｜【必做】感叹句**　独立表达：他跑得多快啊！ 可用词语（次序打乱，不要求全部唯一用法）：fast / he / How / runs。

## C 独立验收

先关闭本章、A/B答案，独立作答。完整12题每题2分，共24分；七个月首轮只计算上方必做题，满分24分、建议至少20分。选做题不进入首轮分母。这是自学建议，不是标准化等级考试。

**C01｜【必做】特殊疑问**　用where问“你的书在哪里”：your book、is。

**C02｜【必做】选择疑问**　Tea or coffee?通常要求怎样回答？

**C03｜【必做】反意疑问**　补全：She isn't tired, ___?

**C04｜【必做】反意疑问**　补全：He likes tea, ___?

**C05｜【必做】反意疑问**　Let's go, ___?

**C06｜【必做】存在句疑问**　把There is a pen here改为一般疑问。

**C07｜【必做】存在句否定**　把There are books here改成“不存在任何书”。

**C08｜【必做】简答**　肯定回答Is there a book here?。

**C09｜【必做】存在与拥有**　“我有一本书”与“桌上有一本书”各用have或there be表达。

**C10｜【必做】感叹**　改正：How a beautiful day!。

**C11｜【必做】句子类别**　Please sit down是什么用途的句子？通常省掉谁？

**C12｜【必做】开放**　写一个be问句和一个普通动作问句，并各给简答。

## 验收标准与错题修复

**七个月首轮：**C必做题至少20/24；A、B、D中的必做项能够独立完成，错题和不稳项能说明题干要求的理由。标为选做的题不作为继续条件。

**第二轮完整复习：**下面保留原全量训练标准；它不覆盖或撤销上面的首轮题单。

- **可以继续：**C达到20/24分，A的24题至少20题能独立完成，B至少3题会做；C中的表达题能说明自己写法的核心理由。不能用“刚看答案后抄对”计入独立完成。
- **需要巩固：**C为16—19分，或某个核心情境的三种任务中连续错两题。按上表标签回到正文对应小节，解释错因后重做同标签的A题，再用自己的词写一个同结构例子。
- **先修复再继续：**C低于16分，或只能认选项、无法完成基本表达。先回本章，处理错得最多的两个标签；不要求盲目刷完整卷第二遍。
- **延迟复测：**隔一天先不看答案，重做错过的C题，再重做A中相应的表达题。复测沿用已有题，不另算新增题量；能够解释并改对再进入下一章。
