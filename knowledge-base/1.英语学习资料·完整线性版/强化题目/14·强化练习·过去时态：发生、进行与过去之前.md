## A 分项强化

**A01｜【必做】过去规则**　按提示补全或完成（写完整句子或短语）：She ___ yesterday.（work）

**A02｜【必做】过去不规则**　按提示补全或完成（写完整句子或短语）：He ___ home yesterday.（go）

**A03｜【必做】过去否定**　按提示补全或完成（写完整句子或短语）：I ___ work yesterday.

**A04｜【必做】过去疑问**　按提示补全或完成（写完整句子或短语）：___ she come yesterday?

**A05｜【必做】过去be**　按提示补全或完成（写完整句子或短语）：They ___ tired last night.

**A06｜【必做】过去进行**　按提示补全或完成（写完整句子或短语）：I ___ reading at eight last night.

**A07｜【必做】过去完成**　按提示补全或完成（写完整句子或短语）：She had ___ before I arrived.（leave）

**A08｜【选做】过去完成进行**　按提示补全或完成（写完整句子或短语）：He had been ___ for an hour.（work）

**A09｜【选做】过去规则**　目标意思：她昨天工作了。 请修正不合形式或不合题意的表达：`She works yesterday.`。

**A10｜【选做】过去不规则**　目标意思：他昨天回家了。 请修正不合形式或不合题意的表达：`He goed home yesterday.`。

**A11｜【选做】过去否定**　目标意思：我昨天没有工作。 请修正不合形式或不合题意的表达：`I didn't worked yesterday.`。

**A12｜【选做】过去疑问**　目标意思：她昨天来了吗？ 请修正不合形式或不合题意的表达：`Did she came yesterday?`。

**A13｜【选做】过去be**　目标意思：他们昨晚很累。 请修正不合形式或不合题意的表达：`They was tired last night.`。

**A14｜【选做】过去进行**　目标意思：我昨晚八点正在读书。 请修正不合形式或不合题意的表达：`I were reading at eight last night.`。

**A15｜【选做】过去完成**　目标意思：我到达前她已离开。 请修正不合形式或不合题意的表达：`She had leave before I arrived.`。

**A16｜【选做】过去完成进行**　目标意思：到当时为止他已持续工作一小时。 请修正不合形式或不合题意的表达：`He had been worked for an hour.`。

**A17｜【必做】过去规则**　独立表达：她昨天工作了。 可用词语（次序打乱，不要求全部唯一用法）：She / worked / yesterday。

**A18｜【必做】过去不规则**　独立表达：他昨天回家了。 可用词语（次序打乱，不要求全部唯一用法）：He / home / went / yesterday。

**A19｜【必做】过去否定**　独立表达：我昨天没有工作。 可用词语（次序打乱，不要求全部唯一用法）：didn't / I / work / yesterday。

**A20｜【必做】过去疑问**　独立表达：她昨天来了吗？ 可用词语（次序打乱，不要求全部唯一用法）：come / Did / she / yesterday。

**A21｜【必做】过去be**　独立表达：他们昨晚很累。 可用词语（次序打乱，不要求全部唯一用法）：last / night / They / tired / were。

**A22｜【必做】过去进行**　独立表达：我昨晚八点正在读书。 可用词语（次序打乱，不要求全部唯一用法）：at / eight / I / last / night / reading / was。

**A23｜【必做】过去完成**　独立表达：我到达前她已离开。 可用词语（次序打乱，不要求全部唯一用法）：arrived / before / had / I / left / She。

**A24｜【选做】过去完成进行**　独立表达：到当时为止他已持续工作一小时。 可用词语（次序打乱，不要求全部唯一用法）：an / been / for / had / He / hour / working。

## 验收标准与错题修复

**七个月首轮：**C必做题至少20/24；A、B、D中的必做项能够独立完成，错题和不稳项能说明题干要求的理由。标为选做的题不作为继续条件。

**第二轮完整复习：**下面保留原全量训练标准；它不覆盖或撤销上面的首轮题单。

- **可以继续：**C达到20/24分，A的24题至少20题能独立完成，B至少3题会做；C中的表达题能说明自己写法的核心理由。不能用“刚看答案后抄对”计入独立完成。
- **需要巩固：**C为16—19分，或某个核心情境的三种任务中连续错两题。按上表标签回到正文对应小节，解释错因后重做同标签的A题，再用自己的词写一个同结构例子。
- **先修复再继续：**C低于16分，或只能认选项、无法完成基本表达。先回本章，处理错得最多的两个标签；不要求盲目刷完整卷第二遍。
- **延迟复测：**隔一天先不看答案，重做错过的C题，再重做A中相应的表达题。复测沿用已有题，不另算新增题量；能够解释并改对再进入下一章。
