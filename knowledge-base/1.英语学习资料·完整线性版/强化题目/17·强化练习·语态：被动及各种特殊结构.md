- **验收必做：**C01、C02、C03、C04、C05、C06、C07、C08、C09、C10、C11、C12。

若A的某个情境不稳，再做同情境标为选做的改错题；只针对卡点加练。原有全卷与完整复习标准保留在文末，供第二轮使用。

## A 分项强化

**A01｜【必做】一般现在被动**　按提示补全或完成（写完整句子或短语）：English ___ here.（speak用被动，分词spoken）

**A02｜【必做】一般过去被动**　按提示补全或完成（写完整句子或短语）：The room ___ yesterday.（clean用被动）

**A03｜【必做】情态被动**　按提示补全或完成（写完整句子或短语）：The work must ___ finished.

**A04｜【必做】进行被动**　按提示补全或完成（写完整句子或短语）：The room is ___ cleaned now.

**A05｜【必做】完成被动**　按提示补全或完成（写完整句子或短语）：The work has ___ finished.

**A06｜【必做】将来被动**　按提示补全或完成（写完整句子或短语）：The house will ___ built.

**A07｜【必做】感官被动**　按提示补全或完成（写完整句子或短语）：He was seen ___ leave.

**A08｜【必做】无被动**　按提示补全或完成（写完整句子或短语）：The accident ___ yesterday.（happen）

**A09｜【选做】一般现在被动**　目标意思：这里有人说英语，要求被动。 请修正不合形式或不合题意的表达：`English speaks here.`。

**A10｜【选做】一般过去被动**　目标意思：房间昨天打扫过了。 请修正不合形式或不合题意的表达：`The room is cleaned yesterday.`。

**A11｜【选做】情态被动**　目标意思：工作必须完成。 请修正不合形式或不合题意的表达：`The work must finished.`。

**A12｜【选做】进行被动**　目标意思：房间正在被打扫。 请修正不合形式或不合题意的表达：`The room is been cleaned now.`。

**A13｜【选做】完成被动**　目标意思：工作已经完成，要求被动。 请修正不合形式或不合题意的表达：`The work has be finished.`。

**A14｜【选做】将来被动**　目标意思：房子将被建造。 请修正不合形式或不合题意的表达：`The house will built.`。

**A15｜【选做】感官被动**　目标意思：有人看见他离开，要求原形宾补对应的被动。 请修正不合形式或不合题意的表达：`He was seen leave.`。

**A16｜【选做】无被动**　目标意思：事故昨天发生了。 请修正不合形式或不合题意的表达：`The accident was happened yesterday.`。

**A17｜【必做】一般现在被动**　独立表达：这里有人说英语，要求被动。 可用词语（次序打乱，不要求全部唯一用法）：English / here / is / spoken。

**A18｜【必做】一般过去被动**　独立表达：房间昨天打扫过了。 可用词语（次序打乱，不要求全部唯一用法）：cleaned / room / The / was / yesterday。

**A19｜【必做】情态被动**　独立表达：工作必须完成。 可用词语（次序打乱，不要求全部唯一用法）：be / finished / must / The / work。

**A20｜【必做】进行被动**　独立表达：房间正在被打扫。 可用词语（次序打乱，不要求全部唯一用法）：being / cleaned / is / now / room / The。

**A21｜【必做】完成被动**　独立表达：工作已经完成，要求被动。 可用词语（次序打乱，不要求全部唯一用法）：been / finished / has / The / work。

**A22｜【必做】将来被动**　独立表达：房子将被建造。 可用词语（次序打乱，不要求全部唯一用法）：be / built / house / The / will。

**A23｜【必做】感官被动**　独立表达：有人看见他离开，要求原形宾补对应的被动。 可用词语（次序打乱，不要求全部唯一用法）：He / leave / seen / to / was。

**A24｜【必做】无被动**　独立表达：事故昨天发生了。 可用词语（次序打乱，不要求全部唯一用法）：accident / happened / The / yesterday。

## C 独立验收

先关闭本章、A/B答案，独立作答。完整12题每题2分，共24分；七个月首轮只计算上方必做题，满分24分、建议至少20分。选做题不进入首轮分母。这是自学建议，不是标准化等级考试。

**C01｜【必做】被动辨认**　The book was written by Amy中write的分词是什么？

**C02｜【必做】执行者**　被动句是否每次都必须带by加执行者？

**C03｜【必做】双宾语**　把They gave me a book改成I作主语的被动。

**C04｜【必做】双宾语**　把They gave Amy a pen改成A pen作主语。

**C05｜【必做】使役**　用have ... done、hair/cut/yesterday表达“我昨天理了发”。

**C06｜【必做】状态**　My keys are lost可以一律当成一次清晰的被动动作吗？

**C07｜【必做】主动被动**　Rice grows here与Rice is grown here都可能正确吗？

**C08｜【必做】动词限制**　改正：This book is belonged to me.

**C09｜【必做】进行否定**　把The door is being painted改否定（paint粉刷）。

**C10｜【必做】完成疑问**　把The letters have been sent改一般疑问（send分词sent）。

**C11｜【必做】受伤**　got hurt可以表达受伤吗？

**C12｜【必做】开放**　同一事件分别用主动和被动表达，指出信息焦点。

## 验收标准与错题修复

**七个月首轮：**C必做题至少20/24；A、B、D中的必做项能够独立完成，错题和不稳项能说明题干要求的理由。标为选做的题不作为继续条件。

**第二轮完整复习：**下面保留原全量训练标准；它不覆盖或撤销上面的首轮题单。

- **可以继续：**C达到20/24分，A的24题至少20题能独立完成，B至少3题会做；C中的表达题能说明自己写法的核心理由。不能用“刚看答案后抄对”计入独立完成。
- **需要巩固：**C为16—19分，或某个核心情境的三种任务中连续错两题。按上表标签回到正文对应小节，解释错因后重做同标签的A题，再用自己的词写一个同结构例子。
- **先修复再继续：**C低于16分，或只能认选项、无法完成基本表达。先回本章，处理错得最多的两个标签；不要求盲目刷完整卷第二遍。
- **延迟复测：**隔一天先不看答案，重做错过的C题，再重做A中相应的表达题。复测沿用已有题，不另算新增题量；能够解释并改对再进入下一章。
