**A09｜【选做】人物主语关系**　目标意思：在这里工作的女孩是埃米，关系词指人。 请修正不合形式或不合题意的表达：`The girl which works here is Amy.`。

**A10｜【选做】物的关系**　目标意思：这是我买的那本书。 请修正不合形式或不合题意的表达：`This is the book what I bought.`。

**A11｜【选做】不重复宾语**　目标意思：这是我买的那本书，不重复它。 请修正不合形式或不合题意的表达：`This is the book that I bought it.`。

**A12｜【选做】地点状语**　目标意思：这是我居住的房子。 请修正不合形式或不合题意的表达：`This is the house which I live.`。

**A13｜【选做】时间状语**　目标意思：我记得我们见面的那天。 请修正不合形式或不合题意的表达：`I remember the day where we met.`。

**A14｜【选做】所属关系**　目标意思：书包是红色的男孩是汤姆。 请修正不合形式或不合题意的表达：`The boy who bag is red is Tom.`。

**A15｜【选做】非限制性**　目标意思：埃米很友善，补充她在这里工作。 请修正不合形式或不合题意的表达：`Amy, that works here, is kind.`。

**A16｜【选做】介词前置**　目标意思：我和她说话的那个人是埃米。 请修正不合形式或不合题意的表达：`The person to that I spoke is Amy.`。

**A17｜【必做】人物主语关系**　独立表达：在这里工作的女孩是埃米，关系词指人。 可用词语（次序打乱，不要求全部唯一用法）：Amy / girl / here / is / The / who / works。

**A18｜【必做】物的关系**　独立表达：这是我买的那本书。 可用词语（次序打乱，不要求全部唯一用法）：book / bought / I / is / that / the / This。

**A19｜【必做】不重复宾语**　独立表达：这是我买的那本书，不重复它。 可用词语（次序打乱，不要求全部唯一用法）：book / bought / I / is / that / the / This。

**A20｜【必做】地点状语**　独立表达：这是我居住的房子。 可用词语（次序打乱，不要求全部唯一用法）：house / I / is / live / the / This / where。

**A21｜【必做】时间状语**　独立表达：我记得我们见面的那天。 可用词语（次序打乱，不要求全部唯一用法）：day / I / met / remember / the / we / when。

**A22｜【必做】所属关系**　独立表达：书包是红色的男孩是汤姆。 可用词语（次序打乱，不要求全部唯一用法）：bag / boy / is / red / The / Tom / whose。

**A23｜【必做】非限制性**　独立表达：埃米很友善，补充她在这里工作。 可用词语（次序打乱，不要求全部唯一用法）：Amy / here / is / kind / who / works。

**A24｜【必做】介词前置**　独立表达：我和她说话的那个人是埃米。 可用词语（次序打乱，不要求全部唯一用法）：Amy / I / is / person / spoke / The / to / whom。

## C 独立验收

先关闭本章、A/B答案，独立作答。完整12题每题2分，共24分；七个月首轮只计算上方必做题，满分22分、建议至少18分。选做题不进入首轮分母。这是自学建议，不是标准化等级考试。

**C01｜【必做】省略**　the book that I read中that能省略吗？

**C02｜【必做】不可省**　the girl who lives here中who能因知道是女孩就删吗？

**C03｜【必做】非限制性**　This book, which I read yesterday, is useful中的which能随意省吗？

**C04｜【必做】范围**　Everything that he said中that常用，是否意味所有类似which都绝对不合语法？

**C05｜【必做】主宾选择**　The city ___ I visited（访问）用that/where哪个符合缺宾语？

**C06｜【必做】主宾选择**　The day ___ I spent here（度过）用that/when哪个？

**C07｜【必做】整句指代**　He won, which made Amy happy中的which可指什么？

**C08｜【识读必做】as**　As is known to all可放句首吗？通常表达什么？

**C09｜【选做】人和物**　先行词包含人和物时，限制性从句通常优先选哪个关系词？

**C10｜【必做】比较**　限定与补充的区别只在句子删去后是否合语法吗？

**C11｜【必做】纠错**　改正：Amy, who she works here, is my friend.

**C12｜【必做】开放**　用book、read、useful写一句带限制性定语从句的句子。
