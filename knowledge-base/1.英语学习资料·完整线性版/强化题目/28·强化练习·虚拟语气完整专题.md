## A 分项强化

**A01｜【必做】现在假设**　按提示补全或完成（写完整句子或短语）：If I ___ you, I would rest.（正式假设形式）

**A02｜【必做】现在假设**　按提示补全或完成（写完整句子或短语）：If I ___ time, I would read.（have，假设现在没时间）

**A03｜【必做】过去假设**　按提示补全或完成（写完整句子或短语）：If I had known, I ___ have helped.

**A04｜【必做】过去条件**　按提示补全或完成（写完整句子或短语）：If she had ___, she would have passed.（study）

**A05｜【必做】现在愿望**　按提示补全或完成（写完整句子或短语）：I wish I ___ more time now.（have）

**A06｜【必做】过去愿望**　按提示补全或完成（写完整句子或短语）：I wish I ___ studied yesterday.

**A07｜【必做】建议要求**　按提示补全或完成（写完整句子或短语）：She suggested that he ___ more.（read，原形虚拟）

**A08｜【选做】would rather**　按提示补全或完成（写完整句子或短语）：I'd rather you ___ tomorrow.（come，偏好你明天来）

**A09｜【选做】现在假设**　目标意思：如果我是你，我会休息，要求正式假设。 请修正不合形式或不合题意的表达：`If I am you, I would rest.`。

**A10｜【选做】现在假设**　目标意思：假如现在有时间，我会读书。 请修正不合形式或不合题意的表达：`If I have time, I would read.`。

**A11｜【选做】过去假设**　目标意思：如果当时知道，我就会帮忙。 请修正不合形式或不合题意的表达：`If I had known, I will have helped.`。

**A12｜【选做】过去条件**　目标意思：要是当时学了，她就通过了。 请修正不合形式或不合题意的表达：`If she has studied, she would have passed.`。

**A13｜【选做】现在愿望**　目标意思：我真希望现在有更多时间。 请修正不合形式或不合题意的表达：`I wish I have more time now.`。

**A14｜【选做】过去愿望**　目标意思：我真希望昨天学过。 请修正不合形式或不合题意的表达：`I wish I would study yesterday.`。

**A15｜【选做】建议要求**　目标意思：她建议他多读，要求原形虚拟结构。 请修正不合形式或不合题意的表达：`She suggested that he reads more.`。

**A16｜【选做】would rather**　目标意思：我宁愿你明天来。 请修正不合形式或不合题意的表达：`I'd rather you will come tomorrow.`。

**A17｜【必做】现在假设**　独立表达：如果我是你，我会休息，要求正式假设。 可用词语（次序打乱，不要求全部唯一用法）：I / If / rest / were / would / you。

**A18｜【必做】现在假设**　独立表达：假如现在有时间，我会读书。 可用词语（次序打乱，不要求全部唯一用法）：had / I / If / read / time / would。

**A19｜【必做】过去假设**　独立表达：如果当时知道，我就会帮忙。 可用词语（次序打乱，不要求全部唯一用法）：had / have / helped / I / If / known / would。

**A20｜【必做】过去条件**　独立表达：要是当时学了，她就通过了。 可用词语（次序打乱，不要求全部唯一用法）：had / have / If / passed / she / studied / would。

**A21｜【必做】现在愿望**　独立表达：我真希望现在有更多时间。 可用词语（次序打乱，不要求全部唯一用法）：had / I / more / now / time / wish。

**A22｜【必做】过去愿望**　独立表达：我真希望昨天学过。 可用词语（次序打乱，不要求全部唯一用法）：had / I / studied / wish / yesterday。

**A23｜【必做】建议要求**　独立表达：她建议他多读，要求原形虚拟结构。 可用词语（次序打乱，不要求全部唯一用法）：he / more / read / She / suggested / that。

**A24｜【选做】would rather**　独立表达：我宁愿你明天来。 可用词语（次序打乱，不要求全部唯一用法）：came / I'd / rather / tomorrow / you。

## C 独立验收

先关闭本章、A/B答案，独立作答。完整12题每题2分，共24分；七个月首轮只计算上方必做题，满分22分、建议至少18分。选做题不进入首轮分母。这是自学建议，不是标准化等级考试。

**C01｜【必做】未来假设**　If it ___ tomorrow, we would stay home，should rain/rained哪些可用？

**C02｜【必做】愿望语体**　I wish I was taller在非正式英语中一定错吗？

**C03｜【必做】过去愿望**　He wishes he studied harder与had studied harder区别是什么？
