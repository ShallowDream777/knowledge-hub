# 折叠答案排版修复

问题：在 Obsidian 展开答案后，`**` 直接显示，多个答案看起来挤在一起。

原因：旧生成器把 Markdown 粗体、普通换行直接放在 HTML 的 details/summary 内。Obsidian 不解析 HTML 内部的 Markdown；HTML 的普通空白换行也不会自动变成显示换行。参见 [Obsidian 官方 HTML 说明](https://obsidian.md/help/html)。

修复：保留折叠外壳，内部统一输出 HTML。题号和粗体改为 strong，每段用 p，原段内逐行内容用 br 明确分行，文本中的比较符号等先进行 HTML 转义。

“答案排版.py”由正文和强化题生成器共同使用，因此再次构建也会保持正确排版。题目、答案文字、导航和验收标准没有改变。

验证：“检查答案排版.py”在修复前能报出缺少段落标签的问题；最小强化题片段同时含裸 `**A01**` 且没有段落标签。修复后检查通过：62份活动文稿、123个折叠块无裸 Markdown 粗体标记，答案有明确段落，强化题号使用 strong。题答配对、导航与原文件校验也通过。此检查针对生成 HTML 的结构，不冒充对用户本机主题的视觉截图验收。
