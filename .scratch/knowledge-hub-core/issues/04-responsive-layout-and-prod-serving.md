# 04 — PC/移动端响应式布局、深浅色护眼主题与单端口生产托管

**What to build:** 平台同时适配桌面浏览器与手机浏览器（移动端顶部汉堡菜单呼出抽屉目录、表格自适应横向滚动、触屏友好操作按钮），支持暖白浅色与深色护眼主题切换；生产构建后由 Express 在 `1906` 端口统一托管前端静态产物与 `/api/*` 接口，开箱即可本地访问或通过 `deploy-to-server` 部署。

**Blocked by:** 02, 03

**Status:** resolved

- [x] Express 后端在 `frontend/dist` 存在时自动托管静态资源并支持 SPA 回退，统一在 `1906` 端口对外服务
- [x] 前后端测试套件全部通过，前端生产构建成功，`http://localhost:1906` 实测可用
